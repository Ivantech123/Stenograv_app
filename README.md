# Стенограф

Запись диктофона (WMA, MP3, M4A, WAV, OGG, FLAC, AMR, видео) превращается в TXT, DOCX и SRT рядом с файлом. Распознаёт whisper.cpp на этом компьютере. Звук никуда не уходит.

Это переписанный на Rust `audio_recognazer`: вместо Python, faster-whisper и tkinter здесь whisper.cpp, Tauri 2 и одно окно.

## Как устроено

```
crates/core   ядро: декодирование, whisper.cpp, чистка текста, запись файлов, подбор режима
crates/cli    stenograf.exe — то же из командной строки
src-tauri     окно: очередь, поток распознавания, события в интерфейс
ui            интерфейс (HTML/CSS/JS без сборщика)
```

Путь одного файла (`core/src/job.rs`):

1. **Куда писать.** Если результат уже есть, по умолчанию появляется `запись (2).txt`, чтобы не затереть правки в старом тексте. В настройках можно выбрать «заменить» или «пропустить».
2. **Модель.** При первом запуске она скачивается с докачкой: обрыв на 700 МБ не начинает загрузку заново. Вместе с ней качается Silero VAD (0,9 МБ).
3. **Звук → 16 кГц моно.** WAV, MP3, FLAC, OGG и M4A декодируются внутри программы (symphonia + rubato). WMA, AMR, Opus и видео идут через ffmpeg: программа найдёт его сама, а если не найдёт, один раз скачает (80 МБ).
4. **Распознавание.** Silero VAD вырезает тишину, затем работает whisper.cpp. Текст появляется в окне по мере распознавания. «Стоп» прерывает сразу, а не в конце файла.
5. **Чистка** (`filter.rs`). Убираются фантомные титры, которые Whisper выдумывает на тишине («Субтитры сделал DimaTorzok», «Продолжение следует…»), пометки вроде «[музыка]» и петли, когда одна фраза повторяется десятки раз.
6. **Абзацы и файлы.** Новый абзац начинается после паузы длиннее 1,4 с. TXT пишется в UTF-8 с BOM, DOCX — Times New Roman 12, поля 25/20/10/20 мм. Запись атомарная: сбой не оставит полфайла.

Пока идёт расшифровка, компьютер не засыпает, процесс работает с пониженным приоритетом, на панели задач виден прогресс.

## Выбор режима под компьютер

`core/src/hardware.rs` определяет железо через WinAPI и реестр, без PowerShell, за миллисекунды:

- ядра, отдельно производительные и энергоэффективные (E-ядра Intel 12+ тормозят whisper, их не занимаем);
- AVX2, FMA, AVX-512;
- свободную память;
- видеокарты с объёмом видеопамяти, встроенные отличаются от дискретных;
- NPU и питание (батарея, заряд);
- свободное место на диске с моделями.

`core/src/advisor.rs` по этим данным оценивает скорость каждого режима и берёт самый точный, который успевает. «Точно» выбирается от ×2 к реальному времени, «Баланс» от ×1. Если памяти или места не хватает, выбор понижается. На батарее с зарядом ниже 50% он сдвигается на ступень легче. После каждой расшифровки реальная скорость сохраняется в `perf.json`, и дальше советник опирается на замеры с этого компьютера, а не на оценку.

Замеры на 46 с диктовки (i5-12400F, RTX 4060):

| Режим | Модель | CPU, 6 потоков | GPU (Vulkan) |
|---|---|---|---|
| Быстро | large-v3-turbo q8, жадный поиск | ≈ ×2 | ×64 |
| Баланс | large-v3-turbo q8, beam 5 | ×1,7 | ×35 |
| Точно | large-v3 q5, beam 5 | ×0,28 | ×15 |

Отсюда правило: на процессоре по умолчанию «Баланс», с видеокартой — «Точно».

## Сборка

```powershell
.\scripts\setup-dev.ps1                        # libclang и Vulkan SDK в tools\
$env:CARGO_TARGET_DIR = "C:\stg"; npm run build:gpu   # установщик NSIS
cargo build --release -p stenograf-cli         # только консольная версия, CPU
cargo test -p stenograf-core
```

Неочевидные места сборки (все в `.cargo/config.toml`):

- Крейт `cmake` подменяет флаги MSVC и теряет `/O2`. Без явного `CMAKE_C_FLAGS_RELEASE` whisper.cpp работает в десятки раз медленнее.
- `GGML_NATIVE=OFF` с базой AVX2/FMA/F16C. Так сборку можно запускать на любом x86 с 2013 года, а не только на той машине, где её собрали.
- Готовые биндинги whisper-rs сгенерированы под Linux и на Windows не подходят, поэтому нужен libclang.
- Для GPU-сборки `CARGO_TARGET_DIR` должен быть коротким (`C:\stg`): иначе MSBuild упирается в лимит путей.

## Командная строка

```powershell
stenograf запись.wma
stenograf D:\диктофон --out D:\тексты --docx
stenograf запись.wma --preset accurate --legal --words "Иванов, А40-12345/2026"
stenograf --doctor      # железо, модели и рекомендованный режим
```

`--legal` и `--words` подсказывают модели, как писать термины и имена, но сами в текст ничего не вставляют. На тестовой записи без словаря номер дела вышел как «А40 Дефис 12345», со словарём — «А40-12345/2026».

Данные программы хранятся в `%LOCALAPPDATA%\Stenograf`: модели, ffmpeg, `settings.json`, `history.json`, `perf.json`.
